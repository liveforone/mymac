# Chan's Neovim Config

## 설치

- 설치는 거의 lazyvim의 :LazyExtras를 사용해서 진행하였다.

## command

### Neotree

- `space` + `e` : open/close neo tree
- `a` : new file/directory
- `d` : delete file/directory
- `r` : rename file/directory

### Telescope

- `space` + `ff` : search file
- `space` + `fp` : search in project

### Buffer
>
> Buffer is not plugin

- `shift` + `h`` : move left tab
- `shift` + `l` : move right tab
- `shift` + `bd` : close tab
